## 安装问题

### Q: pip install mini2fa 失败

**可能原因**：
1. Python 版本过低（需要 >= 3.10）
2. 依赖安装失败（pyzbar、Pillow、cryptography）
3. 网络问题

**解决方案**：

```bash
# 检查 Python 版本
python --version

# 升级 pip
pip install --upgrade pip

# 使用国内镜像源
pip install mini2fa -i https://pypi.tuna.tsinghua.edu.cn/simple

# 如果 pyzbar 安装失败（Windows）
# 需要安装 Visual C++ Redistributable
# 下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe
```

### Q: 导入 mini2fa 时报错 ModuleNotFoundError

**可能原因**：包未正确安装或路径问题

**解决方案**：

```bash
# 重新安装
pip install --force-reinstall mini2fa

# 如果使用虚拟环境，确保已激活
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate  # Windows

# 验证安装
python -c "import mini2fa; print(mini2fa.__version__)"
```

### Q: pyzbar 找不到 zbar 动态库

**可能原因**：系统缺少 zbar 库

**解决方案**：

```bash
# Ubuntu/Debian
sudo apt-get install libzbar0

# CentOS/RHEL
sudo yum install zbar

# macOS
brew install zbar

# Windows
# pyzbar 通常自带 zbar DLL，如果仍有问题：
# 1. 下载 zbar Windows 版本
# 2. 将 libzbar-64.dll 放到 Python 安装目录或 PATH 中
```

## 使用问题

### Q: 如何查看当前版本？

```bash
mini2fa --version
```

### Q: 如何禁用 TUI 模式？

```bash
mini2fa --no-tui
```

### Q: 命令行模式如何获取验证码？

```bash
# 列出所有账号
mini2fa list -p <password>

# 获取验证码（ID 从 list 命令获取）
mini2fa get -p <password> <id>
```

### Q: 如何修改主密码？

在 TUI 交互模式中：
1. 选择 `7. 修改主密码`
2. 输入当前主密码
3. 输入新密码（满足强度要求）
4. 确认新密码
5. 设置新的密保提示（可选）

### Q: 如何添加账号？

在 TUI 交互模式中：
1. 选择 `1. 添加账号（扫码图片）`
2. 输入二维码图片路径
3. 输入分类（可选）
4. 输入备注（可选，最多 20 字）
5. 确认添加

**支持的图片格式**：PNG、JPG、BMP、GIF 等常见格式

### Q: 如何删除账号？

在 TUI 交互模式中：
1. 选择 `4. 删除账号`
2. 选择要删除的账号
3. 输入确认短语：`YES, delete <issuer> - <account>`

**注意**：删除操作不可恢复！

### Q: 如何导出备份？

在 TUI 交互模式中：
1. 选择 `5. 导出备份`
2. 输入导出路径（直接回车使用默认路径）
3. 导出成功

**默认路径**：`~/.mini2fa/backups/mini2fa_backup_<时间戳>.json`

### Q: 如何导入备份？

在 TUI 交互模式中：
1. 选择 `6. 导入备份`
2. 输入备份文件路径
3. 如果是跨机备份，输入备份对应的主密码
4. 预览导入内容
5. 确认导入
6. 冲突账号逐个询问

**导入三态**：
- 本机空库 + 跨机备份：先采用备份主密钥，再原样入库
- 本机已有账号 + 跨机备份：用备份密钥解密重加密，本机密码不变
- 同机备份：直接用当前密码解密

### Q: 如何搜索账号？

在查看验证码页面：
1. 选择 `2. 查看验证码`
2. 输入搜索关键词（非数字文字）
3. 搜索范围：issuer、account、notes
4. 搜索结果实时更新

## 安全问题

### Q: 主密码忘记了怎么办？

**答案**：**无法恢复**。主密码用于加密所有数据，没有后门。

**建议**：
1. 设置密保提示（但不要泄露密码）
2. 定期导出备份
3. 使用密码管理器保存密码

### Q: 密码强度要求是什么？

- 长度 ≥ 6 位
- 必须包含大写字母、小写字母和数字

**建议**：
- 使用 12 位以上的强密码
- 包含特殊字符（虽然不是必需）
- 不要使用常见密码

### Q: 命令行模式的密码安全吗？

**答案**：**不完全安全**。`-p` 参数会在命令历史中可见。

**建议**：
- 在脚本中使用环境变量或配置文件
- 不要在共享环境中使用命令行模式
- 使用后清理命令历史

### Q: 备份文件安全吗？

**答案**：**相对安全**。备份文件仍需主密码才能解密。

**建议**：
- 妥善保管备份文件，不要泄露
- 不要将备份文件提交到版本控制
- 定期备份

### Q: 如何保护数据目录？

**数据目录位置**：`~/.mini2fa/`

**保护措施**：
- 设置目录权限（Linux/macOS）：`chmod 700 ~/.mini2fa`
- 不要共享数据目录
- 定期备份

## 数据问题

### Q: 如何迁移数据到另一台机器？

**步骤**：

1. **在旧机器导出备份**
   ```bash
   mini2fa  # TUI 模式
   # 选择 5. 导出备份
   ```

2. **传输备份文件到新机器**

3. **在新机器导入备份**
   ```bash
   mini2fa  # TUI 模式
   # 选择 6. 导入备份
   # 输入备份文件路径
   # 输入备份对应的主密码
   ```

**注意**：导入后本机密码变为备份的主密码。

### Q: 如何备份数据？

**方法 1：导出备份**
```bash
mini2fa  # TUI 模式
# 选择 5. 导出备份
```

**方法 2：直接复制数据目录**
```bash
# 复制整个数据目录
cp -r ~/.mini2fa /path/to/backup/
```

**建议**：定期备份，妥善保管备份文件。

### Q: 数据库损坏了怎么办？

**症状**：程序提示"数据库损坏或操作失败"

**解决方案**：
1. **从备份恢复**
   ```bash
   mini2fa  # TUI 模式
   # 选择 6. 导入备份
   ```

2. **如果没有备份**
   - 删除损坏的数据库：`rm ~/.mini2fa/mini2fa.db`
   - 重新运行程序（会创建新数据库）
   - 重新添加账号

**预防措施**：定期导出备份。

### Q: 导入备份时提示"主密码不匹配"

**可能原因**：
1. 输入的主密码错误
2. 备份文件损坏
3. 备份文件格式错误

**解决方案**：
1. 确认主密码正确
2. 检查备份文件是否完整
3. 如果是跨机备份，确保输入的是备份对应的主密码

### Q: 导入备份时提示"备份文件格式错误"

**可能原因**：
1. 文件不是 JSON 格式
2. JSON 格式不正确
3. 缺少必要字段

**解决方案**：
1. 检查文件内容是否为有效 JSON
2. 确保文件包含 `version` 和 `accounts` 字段
3. 重新导出备份

## 错误处理

### Q: 程序提示"密码错误次数过多，程序将退出"

**原因**：连续 3 次输入错误密码

**解决方案**：
1. 确认密码正确
2. 如果忘记密码，无法恢复（只能重新开始）

### Q: 程序提示"主密码设置失败"

**原因**：连续 5 次设置密码失败（密码不满足要求或两次不一致）

**解决方案**：
1. 确保密码满足强度要求（≥6 位，包含大小写字母和数字）
2. 确保两次输入的密码一致
3. 重新运行程序

### Q: 程序提示"文件不存在"

**原因**：输入的文件路径不正确

**解决方案**：
1. 检查文件路径是否正确
2. 使用绝对路径
3. Windows 拖拽文件时会带引号，程序会自动去除

### Q: 程序提示"未识别到有效的二维码"

**原因**：图片中没有二维码或二维码不清晰

**解决方案**：
1. 确保图片包含二维码
2. 确保二维码清晰可读
3. 尝试使用其他图片
4. 程序会自动预处理图片（灰度、增强对比度、缩放）

### Q: 程序提示"该二维码是 HOTP 协议"

**原因**：Mini2FA 只支持 TOTP，不支持 HOTP

**解决方案**：
1. 使用支持 HOTP 的工具
2. 如果可能，将 HOTP 切换为 TOTP

### Q: 程序提示"账号已存在"

**原因**：要添加的账号已经存在（相同 issuer + account）

**解决方案**：
1. 查看现有账号：选择 `2. 查看验证码`
2. 编辑现有账号：选择 `3. 编辑账号`
3. 删除现有账号后重新添加

### Q: 程序提示"无效的选择"

**原因**：输入的编号不在有效范围内

**解决方案**：
1. 查看账号列表，确认有效编号
2. 输入正确的编号
3. 输入 `0` 返回主菜单

### Q: 程序提示"请输入数字"

**原因**：输入了非数字字符

**解决方案**：
1. 输入数字编号
2. 输入 `0` 返回主菜单

### Q: 程序提示"路径不能为空"

**原因**：输入的路径为空

**解决方案**：
1. 输入有效的文件路径
2. 使用默认路径（直接回车）

### Q: 程序提示"文件名包含非法字符"

**原因**：文件名包含 `* ? < > | "` 字符

**解决方案**：
1. 修改文件名，去除非法字符
2. 使用其他文件名

### Q: 程序提示"备份主密码错误"

**原因**：输入的备份主密码不正确

**解决方案**：
1. 确认备份对应的主密码
2. 如果忘记密码，无法恢复备份

### Q: 程序提示"备份文件中没有账号数据"

**原因**：备份文件中没有账号信息

**解决方案**：
1. 检查备份文件是否完整
2. 重新导出备份

### Q: 程序提示"导出失败"

**原因**：导出过程中出现错误

**解决方案**：
1. 检查导出路径是否有写权限
2. 检查磁盘空间是否充足
3. 重试导出操作

### Q: 程序提示"更新失败"

**原因**：编辑账号时出现错误

**解决方案**：
1. 检查账号是否存在
2. 重试编辑操作
3. 如果问题持续，从备份恢复

### Q: 程序提示"删除失败"

**原因**：删除账号时出现错误

**解决方案**：
1. 检查账号是否存在
2. 重试删除操作
3. 如果问题持续，从备份恢复

### Q: 程序提示"获取密钥失败"

**原因**：无法解密账号密钥

**解决方案**：
1. 检查主密码是否正确
2. 重试操作
3. 如果问题持续，从备份恢复

### Q: 程序提示"初始化失败"

**原因**：首次设置主密码时出现错误

**解决方案**：
1. 检查数据目录是否有写权限
2. 删除数据目录后重试：`rm -rf ~/.mini2fa/`
3. 如果问题持续，检查 Python 环境

### Q: 程序提示"数据库无法打开"

**原因**：SQLite 数据库文件损坏或被锁定

**解决方案**：
1. 检查数据库文件是否存在
2. 检查文件权限
3. 如果损坏，从备份恢复

## 其他问题

### Q: Mini2FA 支持哪些 OTP 类型？

**答案**：只支持 TOTP（Time-based One-Time Password）。

**不支持**：
- HOTP（HMAC-based One-Time Password）
- Steam Guard
- 其他自定义 OTP 类型

### Q: Mini2FA 支持哪些哈希算法？

**答案**：SHA1、SHA256、SHA512。

**默认**：SHA1（大多数服务使用）

### Q: Mini2FA 支持哪些平台？

**答案**：
- Windows 10/11
- Linux（主流发行版）
- macOS

**系统要求**：
- Python >= 3.10
- 终端支持 ANSI 转义序列

### Q: Mini2FA 如何保证数据安全？

**答案**：
- 双层密钥加密（PBKDF2 + AES-256-GCM）
- 主密码通过 PBKDF2-SHA256（600k 迭代）派生密钥
- 派生密钥加密随机生成的 master_key
- master_key 加密每个账号的 secret
- 修改密码只重加密 master_key，数据库密文不变

### Q: Mini2FA 是开源的吗？

**答案**：是的，使用 GPL-3.0-or-later 许可证。

**GitHub**：https://github.com/Duroxi/Mini2FA
