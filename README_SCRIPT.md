# Mini2FA 脚本版

## 简介

Mini2FA 脚本版是一个基于 Python 的本地 TOTP 双因素认证工具，通过图片扫码方式添加账号，加密存储密钥，并生成 6 位验证码。

## 功能特性

- 📱 **扫码添加**：从图片文件识别二维码，解析 OTP URI
- 🔑 **验证码生成**：符合 RFC 6238 标准的 TOTP 算法
- 🔐 **AES-256 加密**：使用 PBKDF2 派生密钥，AES-256-GCM 加密存储
- 💾 **备份恢复**：支持 JSON 格式导入导出
- 🖥️ **跨平台**：支持 Windows/Linux/macOS

## 安装

### 1. 克隆项目

```bash
cd Mini2FA
```

### 2. 创建虚拟环境（推荐）

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

## 使用

### 启动程序

```bash
python main.py
```

### 首次使用

1. 首次运行时，程序会提示设置主密码
2. 请牢记主密码，丢失将无法恢复数据
3. 密码长度至少 6 位

### 添加账号

1. 从服务提供商获取二维码图片（截图或拍照）
2. 选择菜单选项 1
3. 输入图片文件路径
4. 确认添加

### 查看验证码

1. 选择菜单选项 2
2. 选择账号
3. 查看当前验证码
4. 按 Enter 复制到剪贴板
5. 输入 q 返回菜单

## 数据存储

程序数据存储在用户主目录下的 `.mini2fa` 文件夹：

```
~/.mini2fa/
├── mini2fa.db        # SQLite 数据库
├── master.key        # 主密钥文件（加密）
└── backups/          # 备份目录
```

## 安全特性

### 加密架构

```
用户主密码
    │
    ▼
PBKDF2-SHA256 (600,000 轮迭代)
    │
    ▼
派生密钥 (256-bit)
    │
    ├──► 加密主密钥文件 (master.key)
    │
    └──► 加密数据库中的 OTP 密钥
```

### 安全建议

1. **主密码选择**
   - 长度至少 12 位
   - 包含大小写字母、数字、特殊字符
   - 使用密码短语（如 `MyS3cureP@ssphrase2024!`）

2. **数据备份**
   - 定期导出备份（菜单选项 6）
   - 备份文件仍需主密码才能解密
   - 将备份存储在安全位置

3. **使用注意事项**
   - 不要在公共电脑上使用
   - 使用后及时关闭终端
   - 定期更新主密码

## 常见问题

### Q: Windows 上 pyzbar 安装失败？

A: pyzbar 依赖 zbar 库，Windows 需要额外安装：
- 下载地址：https://github.com/NaturalHistoryMuseum/pyzbar/releases
- 或者使用 `pip install pyzbar`（较新版本会自动处理）

### Q: 忘记主密码怎么办？

A: 由于采用强加密，忘记主密码将无法恢复数据。请务必牢记主密码。

### Q: 如何在多台电脑间同步？

A: 复制 `~/.mini2fa/` 文件夹到目标电脑，使用相同的主密码即可。
